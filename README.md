# Modeste Ameda (flutter_application_1)

Aplikasi konveksi & bordir. Login demo: email berisi "admin" -> mode admin, selain itu -> pelanggan.

## Cara menjalankan
Folder platform (android, ios, web, dll) belum ada di zip ini. Generate dulu:

    flutter create . --project-name flutter_application_1
    flutter pub get
    flutter run

`flutter create .` tidak menimpa folder `lib/`.
